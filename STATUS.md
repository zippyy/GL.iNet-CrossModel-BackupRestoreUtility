# Native router package status

The `main` branch contains the canonical 2.0 native package implementation.
Automated verification and the standalone architecture-independent IPK build
are active. See [docs/IMPLEMENTATION-MATRIX.md](docs/IMPLEMENTATION-MATRIX.md)
for the checked-in behavior/hardware-certification boundary and the root README
for installation and controller examples.

The Docker/Node.js edition is isolated on the `docker` branch and is not part
of the router IPK or its release workflow.
